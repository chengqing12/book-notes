# 父权制下“女性悲剧”的男性角色功能——拉康视角下的“包法利夫人”和“包法利先生”

- **书名**：《包法利夫人》（Madame Bovary）
- **原著作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **文献作者**：任元元（南昌大学人文学院中文系，指导教师：孟广明 副教授）
- **文献类型**：硕士学位论文（2013）
- **关键词**：父权制、女性悲剧、包法利先生、男性角色功能、他者欲望

## 一句话总结

以拉康视角重读《包法利夫人》，指出男性在“女性悲剧”中既是父权制的代理人又是“替罪羊”，女性悲剧话语同时遮蔽了男性自身的结构性悲剧。

## 各章一句话看点

1. **第一章 绪论**——梳理父权制下女性失语、被物化的处境，提出以拉康理论重审包法利夫妇角色的研究路径。
2. **第二章 “父权”与“父权制”的话语建构**——从话语与权力的关系出发，说明父权文化如何逐层建构，并借“父亲之名”“菲勒斯”解释主体进入象征秩序的过程。
3. **第三章 《包法利夫人》：填补“实在界”空缺的“女性悲剧”话语经典**——小说以“伪实在”的幻象空间安放无家可归的主体：艾玛压抑自我、扮演男性欲望中的好妻子，男性则被父亲之法所困，借凝视与谎言维持身份。
4. **第四章 父权制下“女性悲剧”话语的补偿意义**——女性悲剧看似反抗，实则以掩盖“大他者”缺失、弥缝男性主体缺失的方式补偿并维护父权制。
5. **第五章 男性：“女性悲剧”不可或缺的角色**——男性既是父权制的代理人，又是被推上祭坛的“替罪羊”：完美男性本不存在，爱玛注定“所遇非人”，而男性也承受着“爱情之殇”的不可承受之重。
6. **第六章 “女性悲剧”话语刻意遮蔽的男性结构性悲剧及男性的角色性焦虑**——男性若接受他者话语便成为被操纵的提线木偶，唯有拒绝他者欲望，才能抵达无意识的真理位置。
7. **第七章 结语**——《包法利夫人》既诉说女性悲剧，也反思男性的结构性境遇；两性解放需要男性认清被遮蔽的真相、放弃虚假的“身份”。
