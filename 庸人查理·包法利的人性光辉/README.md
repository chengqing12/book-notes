# 庸人查理·包法利的人性光辉

- **书名**：《包法利夫人》（Madame Bovary）
- **原著作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **文献作者**：张婷（乌鲁木齐职业大学师范学院）
- **文献类型**：期刊论文
- **关键词**：《包法利夫人》、查理·包法利、一般人、人性

## 一句话总结

为“庸人”查理翻案：在平庸怯懦的外壳之下，他保有善良天性、对自由与幸福的向往，以及呆板无趣表象下真挚的浪漫情思。

## 各章一句话看点

1. **一、平庸怯懦包裹下的善良天性**——查理出身普通、才智平庸却天性驯良，在同学的嘲笑与考试的失败中默默忍受，恪守本分、善待他人，从不怨天尤人。
2. **二、循规蹈矩之外对自由的渴求、对幸福的向往**——长期被母亲和第一任妻子安排控制，他压抑着对自由的渴望，也曾以逃课、坐酒馆等方式短暂品尝自由的滋味。
3. **三、呆板无趣表象下的浪漫情思**——与艾玛的再婚是他一生中真正的主动选择，他把全部深情与浪漫寄托在这段婚姻中，木讷外表下藏着真挚而笨拙的爱。
