# 对包法利先生的重新解读

- **书名**：《包法利夫人》（Madame Bovary）
- **原著作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **文献作者**：吴幸（南京师范大学文学院）
- **文献类型**：期刊论文
- **关键词**：包法利先生、婴儿、虚化、神性、兽性

## 一句话总结

把查理·包法利视为“从未成长过的婴儿”，从动物性、喜剧性与神性三个层面重估这个常被忽视的男性人物，并剖析福楼拜转换叙事视角、故意虚化人物的匠心。

## 各章一句话看点

1. **一、蠢钝到让人愤怒的动物性**——夏尔终生依赖母亲与妻子，像一头未断奶的幼兽，对外界缺乏反应，其蠢钝既令人愤怒也令人怜悯。
2. **二、福楼拜的匠心独运**——福楼拜故意留下纳博科夫所说的“破绽”，并用叙述视角的转换模糊叙述人与人物的声音，使读者在认同与疏离之间动摇对人物的确定理解。
3. **三、喜剧的光荣**——借莫里哀开创的喜剧传统，说明夏尔这类“没有性格的人”同样具有喜剧观照价值，其木讷与迟钝构成含泪的笑。
4. **四、神性气质的挥发**——夏尔对艾玛无私而纯洁的爱在婚后缓慢释放，艾玛死后他仍以她的方式生活，成为全书唯一获得救赎的人。
