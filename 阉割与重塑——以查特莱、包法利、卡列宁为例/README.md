# 阉割与重塑——以查特莱、包法利、卡列宁为例

- **书名**：《包法利夫人》（Madame Bovary）
- **原著作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **文献作者**：赵世昌（西北民族大学文学院，指导教师：罗文敏 副教授）
- **文献类型**：硕士学位论文（2013）
- **关键词**：阉割、重塑、查特莱、包法利、卡列宁

## 一句话总结

以查特莱、包法利、卡列宁三个男性形象为案例，分析肉体、精神与多重“阉割”的表征与成因，尝试重塑被作者与批评者共同贬抑的男性群像。

## 各章一句话看点

1. **引言**——从“阉割”母题与既有研究出发，指出男性形象在文学评论中的“失语”，提出“阉割与重塑”的反经典批评路径。
2. **一、身体残缺的“查特莱”：作者无意识的“阉割焦虑”在作品中的投射仪式**——查特莱的身体残缺源于儿子对父亲的恐惧与对母亲的依恋，劳伦斯借“阉割仪式”的书写释放自身的阉割焦虑。
3. **二、精神阉割的“包法利”：谁赋予了他懦弱的天性**——福楼拜为突出艾玛而让包法利在文本中“失语”，评论界又用社会历史批评和女性主义对其二次“阉割”，共同塑造了懦弱无能的形象。
4. **三、多重阉割的“卡列宁”：“卡列宁”并非一条狗**——卡列宁承受面相丑化与精神萎靡的双重阉割，作者与批评者的“合谋”将其贬低；以格雷马斯角色模式重读，可还原其责任感与悲剧性。
5. **结语**——为懦弱男性形象“立言”，揭示“阉割”母题在文学中的普遍性，并尝试重塑男性群像、建构更合理的家庭伦理。
