# 《包法利夫人》

- **书名**：《包法利夫人》（Madame Bovary）
- **作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **笔记作者**：郑双（伊犁师范大学）
- **关键词**：福楼拜、《包法利夫人》、空间叙事、女性主义

## 一句话总结

本文以田庄、修道院、侯爵府、农展会、葬礼五个空间为线索，揭示艾玛如何在父权与资产阶级的双重规训下，从一个满怀浪漫幻想的乡村少女一步步走向毁灭，终其一生都未能拥有一片真正属于自己的空间。

## 各章看点

1. **拜尔托的田庄和修道院：乡村少女与父权的禁锢**——父亲包办婚姻、母亲角色缺席，修道院的监视与偷偷流传的浪漫小说共同把艾玛塑造成父权期待中的女性。
2. **侯爵府：小资产阶级的妻子与精神出轨**——镀金男性肖像与性别化的空间划分暴露贵族父权秩序，艾玛只能被动等待子爵的邀请，止步于精神出轨。
3. **农展会：地主乡绅的情人与身体出轨**——罗道耳弗的甜言蜜语与主席台表彰老农妇形成讽刺对照，揭示底层农妇与中产女性身体被剥削的同构性。
4. **艾玛的葬礼：小资产阶级的葬礼与个体的毁灭**——查理以新婚礼服和隆重棺椁将艾玛"洗白"为忠贞妻子，资产阶级权力在她死后完成了最后一次规训。
5. **结语**——艾玛始终身处父亲、丈夫或情人的空间，作品由此提出女性如何突破规训、建构独立生存空间的深刻命题。
