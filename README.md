# 《包法利夫人》

- **书名**：《包法利夫人》（Madame Bovary）
- **作者**：居斯塔夫·福楼拜（Gustave Flaubert）
- **文献类型**：相关研究文献 5 篇
- **关键词**：福楼拜、《包法利夫人》、空间叙事、女性主义、男性形象、拉康

## 一句话总结

小说讲述受过修道院贵族化教育的乡村少女艾玛，因不满平庸的婚姻与生活，先后与罗道尔夫、莱昂偷情并挥霍举债，最终在浪漫幻想破灭与债务逼迫下服毒自尽，留下查理在真相与悲痛中郁郁而终。

## 各篇一句话看点

1. **父权规训下的女性生存困境——论《包法利夫人》的空间隐喻**（郑双，伊犁师范大学）——以田庄、修道院、侯爵府、农展会、葬礼五个空间为线索，揭示艾玛如何在父权与资产阶级的双重规训下走向毁灭，终其一生都未能拥有一片真正属于自己的空间。
2. **对包法利先生的重新解读**（吴幸，南京师范大学）——把查理·包法利看作“从未成长过的婴儿”，从动物性、喜剧性与神性三个层面重估这个常被忽视的男性人物，并剖析福楼拜转换叙事视角的匠心。
3. **庸人查理·包法利的人性光辉**（张婷，乌鲁木齐职业大学）——为“庸人”查理翻案：在平庸怯懦的外壳之下，他保有善良天性、对自由与幸福的向往，以及笨拙却真挚的浪漫情思。
4. **父权制下“女性悲剧”的男性角色功能——拉康视角下的“包法利夫人”和“包法利先生”**（任元元，硕士学位论文）——借拉康理论指出男性在“女性悲剧”中既是父权制的代理人又是“替罪羊”，女性悲剧话语同时遮蔽了男性自身的结构性悲剧。
5. **阉割与重塑——以查特莱、包法利、卡列宁为例**（赵世昌，硕士学位论文）——以查特莱、包法利、卡列宁三个男性形象为案例，分析肉体、精神与多重“阉割”的成因，并尝试重塑被作者与批评者共同贬抑的男性形象。
